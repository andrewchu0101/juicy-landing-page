# 公開上線前檢查清單

> 目的：讓「上線前還差什麼」一眼可見。每項標明負責票或待決人，以及目前狀態。
> 本文件只彙整，**不實作、不核准、不豁免**任何既有要求。標「待決」的項目都是尚未核准的建議或未回答的問題。
> 資料來源：`issues/014`、`docs/06-test-plan.md`「缺口分類」B、`docs/04-sad.md`「運作、風險與未決」、`docs/03-srs.md` NFR-06／NFR-09、`docs/01-brief.md`。
> 建立日期：2026-11-10。狀態欄是當天查得到的事實；沒有執行證據的一律標「未執行」。

## 狀態用語

| 狀態 | 意思 |
|---|---|
| 待決 | 需要專案擁有者回答或核准，沒有答案前不能開始 |
| 未開始 | 有負責票或負責人，尚未動工 |
| 受阻 | 有負責票，但被其他票或決策擋住（寫明擋住的對象） |
| 未執行 | 驗證尚未跑過 |
