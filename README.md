# Juicy Calendar 官方網站

把球拖進日曆，就能建立時間區塊。不用輸入時間數字，離線使用，不需要帳號。

這個專案是 **Juicy Calendar** 的介紹網站。你可以在網頁上直接試用，覺得合適再下載 Windows 版。

- 網站：<https://juicy-landing-page-tau.vercel.app/>（目前的暫時網址，正式網域尚未決定）
- 桌面 App：[andrewchu0101/juicy-calendar](https://github.com/andrewchu0101/juicy-calendar)

## 你可以在這裡做什麼

### 1. 線上試用

打開網站，往下就是試用區，不用安裝、不用註冊。

| 操作 | 方法 |
| --- | --- |
| 拿出一顆球 | 在日曆旁按住球不放 |
| 建立時間區塊 | 把球拖到日曆上放開 |
| 調整位置 | 直接拖移已建立的時間區塊 |

試用日曆是連續三天、每天 10:00 到 15:00。

**請用電腦與滑鼠體驗。** 試用需要有滑鼠指標與懸停能力的輸入裝置；手機或平板上，網站只會顯示產品預覽圖。

### 2. 下載 Windows 版

下載區在試用區下方，按「下載 Windows 版」即可取得免安裝 `.zip`。網頁上也有「免安裝 .zip」與「原始碼」的連結。

下載前請先知道：

- **系統需求：** Windows 10 1803 以上的 64 位元系統。更舊的系統與 32 位元不支援。
- **需要 WebView2：** 電腦要已安裝 Microsoft Edge WebView2 執行階段。免安裝版不會幫你安裝，缺少時請先到微軟官方網站安裝。
- **使用方式：** 解壓縮後執行 `juicy-calendar.exe`，並保留 `portable.flag`。你的資料會存在旁邊的 `data` 資料夾。
- **SmartScreen 警告：** 免安裝版沒有簽章，Windows 可能顯示「Windows 已保護您的電腦」。確認檔案來自本專案的 Releases 後，選「更多資訊」，再選「仍要執行」。
- **驗證下載：** 網頁下載區列出官方的 SHA-256 雜湊。下載後在 PowerShell 執行 `Get-FileHash <檔案路徑>`，結果必須與網頁上的雜湊完全相同；不同就不要執行。

## 試用版與桌面版的差異

網頁試用是瀏覽器版，只開放長按出球、拖球放置、拖移區塊三項操作。調整區塊長度、命名、刪除、復原等功能，請下載桌面版體驗。桌面版的功能以下載後為準。

## 隱私

- 試用區的內容（區塊標題與時間）**不會上傳、不會保存**，重新整理頁面就會消失。
- 網站只會在你的瀏覽器記住一件事：你選的介面語言。
- 桌面版離線使用、不需要帳號，資料只存在你的電腦。

## 語言

網站支援繁體中文與英文。第一次進入時，瀏覽器語言是中文（含各地區）就顯示繁體中文，其他語言顯示英文，也可以隨時手動切換。

## 已知限制

- 網站尚在開發中，部分功能與連結還沒完全開放。
- 目前只提供 Windows 版，沒有 macOS、Linux 或行動裝置版本。
- 試用只在電腦與滑鼠上設計與測試，觸控與其他瀏覽器的互動尚未驗證。

## 給開發者

想在本機執行這個網站：

```bash
npm install            # 依 package-lock.json 安裝
npm run dev            # 開發伺服器
npm run build          # 型別檢查加正式建置
npm run preview        # 預覽建置結果：http://127.0.0.1:4173/
npm test               # 單元與整合測試（vitest）
npm run test:e2e       # 瀏覽器端對端測試（Playwright）
```

需求與設計文件在 [`docs/`](docs/)，協作規則見 [`AGENTS.md`](AGENTS.md) 與 [`CODING_STANDARD.md`](CODING_STANDARD.md)。
