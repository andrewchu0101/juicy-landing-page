# 階段提示詞卡

通用版。`＜＞` 換成你的內容；`@路徑` 是讓 agent 讀檔的引用。Claude Code 用 `/技能`，Codex 用 `$技能`。

| 檔案 | 何時用 |
|---|---|
| [00-sandbox.md](00-sandbox.md) | 想法還很模糊：在**獨立資料夾**探索、比較，最後收斂成簡版 PRD |
| [01-stages.md](01-stages.md) | 正式專案：需求 → PRD → SRS → 設計 → 測試計畫 → 拆票 → 實作 → 除錯 → 變更 → 交付，共 11 張卡 |
| [02-join-existing.md](02-join-existing.md) | 加入別人的專案、或接手舊專案 |

## 用法

1. 一張卡 = 一個階段。同階段的訪談與寫檔留在**同一對話**；換階段前確認決策已寫進檔案。
2. 每張實作工單**另開新對話**，重新指定工單與規格。
3. 只輸入技能名稱，agent 不知道你的專案範圍；要附路徑與限制。
4. 每階段產出後，由**人**依 Gate 審查，再往下一張卡。
5. 技能不存在或被限制時，改用普通動作，不虛構技能。
